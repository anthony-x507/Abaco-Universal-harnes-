# Aegis Agent Factory

A self‑aware, plugin‑driven **universal technology platform** that can create, train, and deploy AI agents across 10+ technical domains. It includes a Codex‑like UI, browser automation, LLM training, SDR/RF analysis, satellite comms, 5G/6G, vehicle ECU, robotics, EW, mesh networking, embedded systems, and knowledge management.

## Quick Start

### Option 1: Docker (recommended)

```bash
docker-compose -f docker-compose.full.yaml up -d

Then open:

· API: http://localhost:8000 
· Interactive API docs: http://localhost:8000/docs 
· Management UI: open ui/factory_panel/index.html in your browser (after API is running)

Option 2: Native Install

Linux/macOS:

./install.sh
./run.sh

Windows:

.\install.ps1
.\run.ps1

Then open ui/factory_panel/index.html.

Configuration

· Copy .env.example to .env and add your API keys (OpenAI, DeepSeek, Telegram, etc.). 
· Edit config/settings.yaml for global settings. 
· Agent templates are in factory/templates/.

Features

Core Agent

· Self‑awareness & time tracking 
· Context summarization (75‑80% threshold) 
· Token budgeting & automatic approval 
· Evidence‑based safety (hard blocks only for severe categories) 
· Memory & notes per agent 
· Delegation to internal scouts & teams

Plugins (Infinite Extensibility)

· Drop folders into plugins/builtin/ with manifest.json and plugin.py. 
· Built‑in examples: web search, scraper, TTS/STT, office, image gen, code tools, browser skills, etc.

Agent Factory

· Create agents from templates (general, researcher, coder, RF analyst, satellite, 5G, automotive, robotics, EW, mesh, embedded, knowledge trainer). 
· Select from 25+ LLM providers (OpenAI, DeepSeek, Anthropic, etc.). 
· 25+ communication channels (Telegram, Discord, Slack, etc.). 
· Deploy agents to GitHub with one click. 
· Browser automation with recording, scheduling, AI skill creation, and state persistence.

Domains

1. LLM Training & Fine‑Tuning
2. SDR / RF Analysis
3. Satellite Communications
4. 5G/6G Wireless
5. Vehicle ECU & RF Security
6. Robotics & Drone Technology
7. Jammers & Electronic Warfare
8. Mesh Networking & IoT Protocols
9. Embedded Systems & FPGA Development

API

The backend exposes a FastAPI server at http://localhost:8000.

· Interactive docs: /docs 
· Health check: /health 
· List agents: GET /v1/agents 
· Create agent: POST /v1/agents 
· Chat (OpenAI compatible): POST /v1/chat/completions 
· List models: GET /v1/models 
· List communication channels: GET /v1/communication 
· Browser automation: /v1/browser/* 
· Scheduler: /v1/scheduler/*

Testing

Run integration tests:

pytest tests/test_integration.py -v

Troubleshooting

· Port 8000 already in use: change port in run.sh or Docker compose. 
· Missing API keys: edit .env and restart. 
· Browser automation fails: install Playwright pip install playwright && playwright install chromium. 
· Sandbox/Docker not available: ensure Docker is running and the user has permissions.

# API Reference

The Aegis Agent Factory exposes a REST API. Below are the most used endpoints.

## Agents
- `GET /v1/agents` – list all agents
- `POST /v1/agents` – create a new agent
- `POST /v1/agents/{id}/start` – start an agent
- `POST /v1/agents/{id}/stop` – stop an agent
- `GET /v1/agents/{id}/status` – get agent status
- `POST /v1/agents/{id}/deploy` – deploy agent to GitHub

## Chat
- `POST /v1/chat/completions` – OpenAI‑compatible chat (non‑streaming or streaming)
- `POST /v1/chat/stream` – direct streaming from LLM provider

## Options
- `GET /v1/models` – list LLM providers
- `GET /v1/communication` – list communication channels
- `GET /v1/plugins` – list loaded plugins

## Browser Automation
- `POST /v1/browser/launch` – launch headless Chrome
- `POST /v1/browser/navigate` – navigate to URL
- `POST /v1/browser/click` – click element
- `GET /v1/browser/screenshot` – take screenshot
- `POST /v1/browser/record/start` / `stop` – record interactions
- `POST /v1/browser/record/save` – save recording as skill
- `GET /v1/browser/record/list` – list saved skills
- `POST /v1/browser/record/replay` – replay a skill
- `POST /v1/browser/test/clicks` – click all elements
- `GET /v1/browser/audit/accessibility` – run axe accessibility audit
- `GET /v1/browser/performance` – get navigation timing metrics
- `GET /v1/browser/network/log` – get network requests/responses

## Scheduler
- `POST /v1/scheduler/add` – schedule a task (run_at or cron)
- `POST /v1/scheduler/nl_add` – schedule from natural language
- `GET /v1/scheduler/list` – list scheduled tasks
- `DELETE /v1/scheduler/{index}` – remove task

## Skill State
- `GET /v1/browser/skills/{skill_name}/state` – get persistent state
- `PUT /v1/browser/skills/{skill_name}/state` – update state
