# Aegis UI Design Language

## Philosophy

The Aegis interface should feel like a **mission control for intelligent agents**. It must be powerful, fast, and intuitive. The user is not just chatting; they are orchestrating agents, plugins, browser automations, and live systems.

**Core principles:**
- **Clarity** – every panel has a purpose; no unnecessary clutter.
- **Depth** – reveal complexity only when needed (progressive disclosure).
- **Speed** – interactions feel instant; streaming and live updates.
- **Control** – the user can resize, collapse, and customize every part of the workspace.
- **Futuristic but familiar** – dark, high‑contrast, with neon accents; the layout should be immediately understandable to anyone who has used a modern IDE or ChatGPT.

## Color Palette

|------|-------|-----|
| Background | Deep space | `#0B0E14` |
| Surface 1 | Panel | `#131720` |

| Surface 3 | Hover | `#222A35` |
| Border | Subtle | `#2A3441` |
| Primary Accent | Cyan | `#00E5FF` |
| Secondary Accent | Purple | `#A78BFA` |
| Success | Green | `#34D399` |
| Warning | Amber | `#FBBF24` |

## Typography

- **Font Family**: Inter (or system UI) for general text; JetBrains Mono for code and terminal.
- **Base size**: 14px, with 16px for chat messages.
- **Weights**: Regular (400), Medium (500), SemiBold (600), Bold (700).
- **Line height**: 1.5 for body, 1.3 for headings.

## Spacing & Sizing

- Base unit: 4px
- Common paddings: 8, 12, 16, 24, 32
- Border radius: 8px for cards, 4px for inputs, 12px for modals.
- Panel min width: 280px; default widths: left sidebar 240px, right panel 360px.

## Iconography

- Use Lucide icons (or Heroicons) at 18–20px size.
- Icons are always accompanied by text labels (except for well‑known actions like close, settings).
- Hover states use accent color.

## Motion & Feedback

- **Transitions**: 150–200ms ease-out for hover, focus, and panel collapse.
- **Streaming text**: typewriter effect with a blinking cursor.
- **Loading states**: skeleton screens for initial loads; pulsing activity dot for background work.
- **Button feedback**: scale on press (0.98), subtle glow on hover.

## Panel Behavior

- All major panels (chat, browser, agents, status, plugins) are **resizable** by dragging edges and **collapsible**.
- Panels can be rearranged via drag-and-drop (future).
- Persistent layout saved to localStorage.

## Accessibility

- High contrast ratios (WCAG AA minimum).
- Full keyboard navigation (Tab, arrows, shortcuts).
- Focus visible states with accent outline.
- ARIA labels for custom controls.

## User Modes

1. **Chat mode** – minimal, focused on conversation.
2. **Workbench mode** – full layout with all panels visible.
3. **Command mode** – Ctrl+K to open command palette for quick actions.

These modes can be toggled from the top bar.
