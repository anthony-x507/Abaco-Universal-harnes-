📁 docker-compose.librachat.yaml

This compose file runs both the LibreChat frontend and our FastAPI backend. It assumes you have the Aegis project folder mounted.

version: '3'

services:
  aegis-api:
    build:
      context: .
      dockerfile: Dockerfile.api   # We'll create this simple Dockerfile below

    ports:
      - "8000:8000"
    volumes:
      - ./data:/app/data

      - PYTHONUNBUFFERED=1

📁 .env.librachat

LibreChat expects certain environment variables. Here we set it to use our API as a custom endpoint.

# LibreChat configuration
HOST=0.0.0.0
PORT=3080

# MongoDB for LibreChat (required for storing conversations)
MONGO_URI=mongodb://mongodb:27017/LibreChat

# Custom endpoint (our Aegis API)
OPENAI_BASE_URL=http://aegis-api:8000/v1
OPENAI_API_KEY=sk-dummy   # LibreChat requires a key; our API ignores it for now

# Models to display
OPENAI_MODELS=gpt-4o-mini,deepseek-chat,claude-3-5-sonnet

# Optional: for streaming
STREAM=true

Important: LibreChat also needs a MongoDB instance. We'll add it to the compose file later, or use an external one. The above compose file didn't include MongoDB; we'll provide an updated version below.

📁 librechat.yaml (Optional Custom Config)

LibreChat supports a YAML configuration file to define custom endpoints, models, and features. Here's a minimal example:

version: 1
endpoints:
  custom:
    - name: "Aegis"
      apiKey: "sk-dummy"
      baseURL: "http://aegis-api:8000/v1"
      models:
        default: ["gpt-4o-mini", "deepseek-chat", "claude-3-5-sonnet"]
      titleConvo: true
      titleModel: "gpt-4o-mini"
      modelDisplayLabel: "Aegis"

Place this file in the project root, and mount it as shown above. LibreChat will then show "Aegis" as a provider.

# Connecting LibreChat to Aegis Agent Factory

This guide explains how to run LibreChat (a ChatGPT/Codex-style UI) with the Aegis Agent Factory as its backend.

## Prerequisites
- Docker and Docker Compose installed.
- The Aegis Agent Factory project folder (with `api/` and `requirements.txt`).
- API keys for any LLM providers you intend to use (e.g., OpenAI, DeepSeek).

## Steps

1. **Create Dockerfile.api** (if not already present) with the content provided in the parent instructions.

2. **Create .env.librachat** with the environment variables shown above.

3. **Create librechat.yaml** (optional) for custom endpoint definition.

4. **Run the stack**:
   ```bash
   docker-compose -f docker-compose.librachat.yaml up -d

5. Access LibreChat: 
6. Open http://localhost:3080 in your browser.
7. Select the Aegis provider: 
8. In LibreChat, choose the "Aegis" endpoint (or the model names you configured). Start chatting.
9. Manage Agents: 
10. Use the Factory API directly or build a custom panel later to create/manage agents. For now, you can use curl or an API client to POST to /v1/agents.

Troubleshooting

· Ensure the Aegis API is reachable from LibreChat container: docker exec -it <librechat_container> curl http://aegis-api:8000/health. 
· Check API logs with docker logs aegis-api. 
· If MongoDB connection fails, ensure the MONGO_URI in .env.librachat matches the service name mongodb.

Next Steps

· Add a custom right-panel to LibreChat to display agent status (can be done by forking the LibreChat repo). 
· Integrate file upload and code execution by extending our API endpoints.
