Lock-safe mapping (integrator):

- There is no `universal/cli/chat.py`. Chat lives in `universal/cli.py` `_cmd_chat`.
- There is no `universal/factory/templates/*.yaml`. Prompts live in `universal/templates/catalog.py`.

- Memory is an Agent field + `memory.json` keyed by agent name. It is not a second registry. Recreate the agent with the same name after process restart to reload facts. `--demo` EchoProvider will not invent "John"; a live or FakeProvider that reads the injected memory will.
