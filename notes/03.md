🔧 How Bun Fits Into the Project

Bun will be used as the package manager and build tool for the desktop UI and future web platform. This means:

· The package.json will be managed with Bun (bun install, bun run build).
· We use Bun's bundler to compile the React/Svelte frontend into static files that pywebview loads.
· Bun becomes an example of a "tool plugin" — a non-AI capability that can be integrated into the hardness.

📄 Example: Bun Tool Plugin

This plugin shows how our system can wrap Bun as a tool, so any agent can use it to run JavaScript/TypeScript, install packages, or build frontends.

plugins/builtin/bun_tool/manifest.json

{
  "name": "bun_tool",
  "version": "0.1.0",
  "description": "Run Bun commands (install, run, build) from the agent.",
  "permissions": ["code_execution"],
  "config": {
    "bun_path": "bun"
  }
}

plugins/builtin/bun_tool/plugin.py

# bun_tool/plugin.py
import subprocess
from plugins.loader import BasePlugin

class Plugin(BasePlugin):
    def initialize(self, config):
        self.bun_path = config.get("bun_path", "bun")
    
    def execute(self, action, parameters):
        if action == "install":
            package = parameters.get("package")
            cmd = [self.bun_path, "install", package]
            result = subprocess.run(cmd, capture_output=True, text=True)
            return {"stdout": result.stdout, "stderr": result.stderr}
        elif action == "run":
            script = parameters.get("script")
            cmd = [self.bun_path, "run", script]
            result = subprocess.run(cmd, capture_output=True, text=True)
            return {"stdout": result.stdout, "stderr": result.stderr}
        elif action == "build":
            cmd = [self.bun_path, "run", "build"]
            result = subprocess.run(cmd, capture_output=True, text=True)
            return {"stdout": result.stdout, "stderr": result.stderr}
        else:
            raise NotImplementedError(f"Action '{action}' not supported by bun_tool")

🔄 Integration with the Factory

When the Agent Factory creates an agent that needs frontend/web capabilities, it can include the bun_tool plugin automatically. This means the agent can:

· Install JavaScript packages.
· Build frontend assets.
· Run Node.js/Bun scripts.

This is exactly the type of "hardness" you're building — a system that can incorporate any digital tool (Bun, Docker, Git, etc.) as a plugin.
