🚀 Hito 5: Guía final + Demo walkthrough

Objetivo

· Documentar todo lo que Universal puede hacer: CLI, SPA, webhook, memoria, Auto, snapshots, medidor de uso.
· Crear una demo guiada que el usuario pueda seguir paso a paso para probar todas las funcionalidades.
· Preparar el producto para su presentación o lanzamiento.

---

📦 Entregables del Hito 5

1. README principal (README.md)

· Resumen ejecutivo: Qué es Universal, para quién es, y qué lo hace especial.
· Instalación: Cómo instalar y ejecutar (con pip o poetry).
· Uso básico: CLI (create, start, ask, chat, deploy, shell) y SPA (serve).
· Funcionalidades avanzadas:
  · Webhook (cómo configurarlo y usarlo).
  · Memoria persistente (memory.json).
  · Modo Auto (run vs ask).
  · Snapshots del registry (reinicio sin pérdida de agentes).
  · Medidor de uso (tokens y costos).
· Plugins: Cómo crear y registrar plugins (con ejemplo de utc_now).
· Despliegue: Cómo usar el ZIP generado.
· Contribución: Cómo extender Universal.

2. Guía de demo (DEMO.md o sección en README.md)

· Paso 1: Iniciar el servidor en modo demo (universal serve --demo).
· Paso 2: Crear un agente researcher con memoria y webhook.
· Paso 3: Probar el modo Auto (pregunta que requiera herramientas).
· Paso 4: Probar el webhook (enviar mensaje por POST /v1/agents/{id}/webhook).
· Paso 5: Probar el medidor de uso (ver tokens y costos en tiempo real).
· Paso 6: Exportar el ZIP del agente.
· Paso 7: Reiniciar el servidor y ver el snapshot del registry.

3. Video demo (opcional, pero recomendado)

· Un video de 5-10 minutos mostrando la demo guiada.
· Puede ser una grabación de pantalla con voz en off explicando cada paso.

4. Presentación del producto (opcional)

· Una pequeña página web o PDF con la propuesta de valor de Universal.
· Incluye comparativa con otros harnesses (LangChain, AutoGen, DeepSeek Harness).

5. Script de instalación y demo automática (opcional)

· Un script demo.sh que:
  1. Instale las dependencias.
  2. Inicie el servidor en modo demo.
  3. Cree un agente de ejemplo.
  4. Muestre un mensaje de "Demo lista".
